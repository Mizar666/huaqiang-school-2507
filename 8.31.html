我们手里的板子是什么

导入

今天每个人手里的核心板叫 ESP32：

名称 含义
ESP 中国乐鑫公司研发的物联网芯片
32 32位高性能微型电脑处理器
功能 自带双核 CPU、板载 Wi-Fi 和蓝牙

别看它只有半张卡大，它是一块货真价实的工业级微型电脑。

因为我们用的是 MicroPython：

  1. 零基础无缝衔接：语法和高一学的 Python 几乎一样

  3. 即时掌控感：你在终端敲一行，板子上的灯就动一下

基础任务：点亮板载蓝灯

实操 · 15 分钟

分发文件：打开 01_blink.py，直接按 F5 运行！

from machine import Pin
import time

led = Pin(2, Pin.OUT)  # 板载蓝灯在引脚 2

while True:
    led.value(1)       # 蓝灯亮
    time.sleep(0.5)    # 等 0.5 秒
    led.value(0)       # 蓝灯灭
    time.sleep(0.5)    # 等 0.5 秒

改参任务：修改 time.sleep 的数字，改出极速快闪（0.1秒）或慢闪（1秒）。

进阶任务：短闪两次，长暗 1.5 秒

进阶 · 前 30% 快速组

基础闪灯改通的同学，挑战修改节奏：

目标效果： 短闪 2 次，然后长暗 1.5 秒，不断循环。

参考思路：

while True:
    # 第一次短闪
    led.value(1); time.sleep(0.1)
    led.value(0); time.sleep(0.1)
    # 第二次短闪
    led.value(1); time.sleep(0.1)
    led.value(0); time.sleep(1.5)  # 长暗 1.5 秒

修改参数并调试出标准双闪效果。

挑战任务：手指引脚触摸开关

挑战 · 前 10% 极速组

不需要按钮，直接用手指当开关！

ESP32 板载电容触摸检测，打开 03_touch.py 运行：

from machine import Pin, TouchPad
import time

led = Pin(2, Pin.OUT)
t = TouchPad(Pin(4))   # GPIO 4 排针支持触摸

while True:
    if t.read() < 250: # 手指触碰排针时读数会变小
        led.value(1)   # 摸上去亮灯
    else:
        led.value(0)   # 松开熄灭
    time.sleep(0.05)

用手指直接触摸板子上的 GPIO 4（D4）金属排针，体验触摸开关！
