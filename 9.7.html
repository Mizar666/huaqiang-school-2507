今天用网页单片机：Wokwi

浏览器里的硬件仿真 · 绝不烧板
什么是 Wokwi？

它是一个运行在浏览器里的虚拟单片机实验室。

  • 不用插真实的板子和数据线；
  • 你在网页里写的 MicroPython 代码，会直接在虚拟芯片上运行；
  • 连错线、写错参数都不会损坏元器件。
已经帮大家接好了灯

现实中板子上自带一颗蓝色小灯，连在 2 号接口 上。

  • 老师已经帮大家在虚拟板子的 2 号接口 接好了一颗蓝色 LED；
  • 代码写 Pin(2, Pin.OUT)（控制 2 号接口输出电平）；
  • 只要点绿键运行，就能看到右边的灯在闪烁！

打开工程
4 步操作
  • 1. 点击上方按钮打开工程；
  • 2. 点击右侧「复制」按钮，全选覆盖粘贴到 Wokwi 的 main.py 中；
  • 3. 点击绿色的 Play (▶) 运行；
  • 4. 观察右侧小蓝灯是否每隔 0.5 秒闪烁一次。
main.py
from machine import Pin
import time

# 2 号接口控制蓝色小灯
led = Pin(2, Pin.OUT)
print("ESP32 虚拟仿真启动！")

while True:
    led.value(1)
    print("灯亮 ●")
    time.sleep(0.5)
    
    led.value(0)
    print("灯灭 ○")
    time.sleep(0.5)

改改看：调出快闪与慢闪

修改 time.sleep() 里的数字
改参数与改颜色

time.sleep(0.5) 括号里的数字代表等待秒数：

  • 快闪（警示灯）：两处 0.5 改成 0.1；

  • 心跳节拍：亮 0.1 秒、暗 0.9 秒！

打开双灯工程
1. 观察接线口

看网页里的电路连线：

  • 红灯接在 2 号接口；
  • 绿灯接在 4 号接口；
  • 负极黑色线共同接到 GND（接地）。
main.py (红绿交替)
from machine import Pin
import time

red = Pin(2, Pin.OUT)    # 红灯接 2 号接口
green = Pin(4, Pin.OUT)  # 绿灯接 4 号接口

while True:
    # 红灯亮，绿灯灭
    red.value(1)
    green.value(0)
    print("红灯亮 ●")
    time.sleep(0.8)
    
    # 红灯灭，绿灯亮
    red.value(0)
    green.value(1)
    print("绿灯亮 ●")
    time.sleep(0.8)

红绿双灯：玩转不同的闪烁节奏

尝试修改代码 · 调出多种灯光节奏
尝试 2 种新节奏
  • 玩法一：同步闪烁
    把两颗灯同时点亮、同时熄灭，模拟双闪应急警示灯！
  • 玩法二：三拍节奏（长短搭配）
    红灯慢悠悠亮 1 秒，绿灯快速短促连续闪 2 次（0.15 秒），体验节奏差！
三拍节奏参考代码
from machine import Pin
import time

red = Pin(2, Pin.OUT)    # 2 号接口
green = Pin(4, Pin.OUT)  # 4 号接口

while True:
    # 红灯长亮 1 秒
    red.value(1); green.value(0); time.sleep(1.0)
    
    # 绿灯连续短闪两次
    red.value(0)
    green.value(1); time.sleep(0.15)
    green.value(0); time.sleep(0.15)
    green.value(1); time.sleep(0.15)
    green.value(0); time.sleep(0.5)

任务二

学会用 Ctrl+C 停下来

死循环必须学会人工叫停
怎么停止运行？

代码里写了 while True，它会一直打印不停：

  • 鼠标在下方 Shell 终端黑框里点一下；
  • 按键盘：Ctrl + C；
  • 看到终端打印出 KeyboardInterrupt，字停住了，说明成功制动！
核心技能达成

单片机程序一直在后台跑，学会用 Ctrl+C 踩刹车是后续所有调试的基本功。

数字递增：心跳计数器

每循环一次，数字加 1
变量累加

很多传感器需要记录采样次数：

右侧代码中 count = count + 1 让数字每隔 0.8 秒自动涨 1。自己改改看，能不能让它每次涨 2 或者涨 10？

count.py
import time

count = 0
print("心跳计数器启动！")

while True:
    count = count + 1
    print("第", count, "次采样...")
    time.sleep(0.8)
