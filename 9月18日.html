步骤 1：外接 LED 面包板接线（定点插孔）

硬件连接

① 地线回路

· 板子 GND ➔ 杜邦线 ➔ 蓝线(-)负极列
· 整条蓝线列成为公共地线

② 串联限流电阻

· 电阻左脚插 15b
· 电阻右脚插 18b（横跨两排，禁止同排）
· 板子 4 号口 ➔ 杜邦线 ➔ 15a

③ 插入 LED（长正短负）

· LED 长脚（正极） 插 18c（连着电阻）
· LED 短脚（负极） 插 蓝线(-)负极列
· 检查无虚接，准备写代码！

实验 1 · 操作：点亮第一盏外接灯

单灯闪烁

Python 
from box import LED
import time

# 初始化 4 号接口 LED
led = LED(4)

while True:
    led.on()       # 开灯
    time.sleep(0.5)
    led.off()      # 关灯
    time.sleep(0.5)

🎯 动手做

  2. 按 F5 运行；
  3. 观察面包板上的 LED 是否每隔 0.5 秒闪烁一次！

实验 2 · 操作：按键控制外接灯

开关量输入

Python 
from box import LED, Button
import time

led = LED(4)
btn = Button(0)   # 板载 BOOT 键

while True:
    if btn.is_pressed():
        led.on()
    else:
        led.off()
    time.sleep(0.05)

实验 3 · 操作：人体触摸感应开关

电容触摸

Python 
from box import LED, Touch
import time

led = LED(4)
touch = Touch(27)   # 27 号触摸脚

while True:
    if touch.is_touched():
        led.on()
    else:
        led.off()
    time.sleep(0.05)

🎯 动手做

  1. 从 27 号口 引出一根杜邦线，露在空中；
  2. 运行代码，用手指捏住这根线的金属针头；
  3. 观察：人体一碰，LED 瞬间点亮！

实验 3 · 变式与规律：看透电容读数

改参思考

Python 
from box import Touch
import time

touch = Touch(27)

while True:
    val = touch.read()
    print("当前电容读数:", val)
    time.sleep(0.3)

💡 规律总结

  1. 运行左侧代码，看 Shell 窗口打印的数字；
  2. 没摸时：读数通常在 500 ~ 700；
  3. 手指摸住时：读数暴跌至 100 ~ 200；
  4. 触摸本质：人体分流了电荷，导致读数变小！

实验 4 · 操作：双 LED 红绿灯交替

双路输出

Python 
from box import LED
import time

red = LED(4)     # 4 号红灯
green = LED(18)  # 18 号绿灯

while True:
    red.on()
    green.off()
    time.sleep(0.5)
    
    red.off()
    green.on()
    time.sleep(0.5)

🎯 动手做

  1. 加插绿灯：18 号脚接第 2 个电阻和绿灯（短脚同样插蓝线负极列）；
  2. 复制代码并运行；
  3. 观察红绿双灯像十字路口一样交替轮流点亮！

实验 4 · 变式挑战：警车爆闪与航行节奏

改参挑战

🛠️ 变式 1：警车交替双爆闪

将循环内部代码替换为：
red.blink(times=2, delay=0.08)
green.blink(times=2, delay=0.08)
观察红绿双灯飞速急闪，体验特警车灯效！

🛠️ 变式 2：无人机航行灯节奏

做“红一长、绿两短”：
red.on(); time.sleep(0.8); red.off()
green.blink(times=2, delay=0.12)
复刻真实无人机夜航防撞指示灯节奏！

💡 规律总结

· red 与 green 是两个独立控制对象
· 代码执行的先后顺序决定了灯光韵律
· 组合不同的闪烁参数就能打造各种装备灯效

实验 5 · 操作：摇滚节奏灯

经典节拍

Python 
from box import LED
import time

red = LED(4)      # 4号红灯 (咚)
green = LED(18)   # 18号绿灯 (啪)

while True:
    # 咚 (Boom)
    red.on()
    time.sleep()   # 填入点亮时间
    red.off()
    time.sleep(0.25)
    
    # 咚 (Boom)
    red.on()
    time.sleep()   # 填入点亮时间
    red.off()
    time.sleep(0.25)
    
    # 啪！ (Clap)
    green.on()
    time.sleep()   # 填入点亮时间
    green.off()
    time.sleep(0.6)

🎯 动手做

  1. 在 time.sleep() 括号中填入测试时间（如 0.1）；
  2. 按 F5 运行代码；
  3. 观察灯光节拍：红灯闪、红灯闪、绿灯闪！
